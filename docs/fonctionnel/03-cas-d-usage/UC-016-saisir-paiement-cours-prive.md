# UC-016 – Saisir ou modifier le paiement d'un cours privé

**Acteur** : Aurélie

**Préconditions** : Le cours privé existe.

## Scénario nominal

1. Aurélie saisit le montant (un seul paiement pour le cours, quel que soit le nombre d'élèves), le statut payé ou non et le moyen de paiement du cours privé.
2. Elle peut les modifier après coup.

## Règles liées

RG-018

## Critères d'acceptation

- Étant donné un cours privé non payé, quand Aurélie saisit le paiement et son moyen, alors le cours privé est marqué payé.
